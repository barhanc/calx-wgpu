About Calx

Calx is a lightweight, pure WebGPU inference runtime written in TypeScript for executing PyTorch ExecuTorch models directly in the browser. It eschews heavy frameworks, graph compilers, and virtual machines in favor of direct GPUBuffer views, hand-written WGSL compute shaders, and static ahead-of-time memory planning.

This demo performs real-time foreground segmentation on live camera video. Camera frames are center-cropped and uploaded directly into WebGPU textures without CPU round-trips. A custom WGSL compute shader unpacks pixels into a planar tensor, evaluates the full PyTorch segmentation model across hand-written convolution and upsampling kernels, and composites the predicted mask over a darkened background.

The entire compute pipeline is recorded into WebGPU command buffers once at startup. Each animation frame simply uploads the latest video snapshot, replays the pre-recorded passes, and copies the result directly to the canvas for smooth, zero-allocation inference.
